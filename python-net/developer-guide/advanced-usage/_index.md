The advanced topics build on the [basic usage](https://docs.groupdocs.com/annotation/python-net/basic-usage/) operations with control over how documents are loaded into the [`Annotator`](https://reference.groupdocs.com/annotation/python-net/groupdocs.annotation/annotator/) and how the annotated result is written back out.

## In this section

- [Loading Documents](https://docs.groupdocs.com/annotation/python-net/loading-documents/) — load from a local disk or a binary stream, and open password-protected files with `LoadOptions`.
- [Saving Documents](https://docs.groupdocs.com/annotation/python-net/saving-documents/) — save only specific annotation types and limit the output to a page range with `SaveOptions`.
- [Generate Document Preview](https://docs.groupdocs.com/annotation/python-net/generate-document-preview/) — render document pages to PNG/JPEG/BMP images with `PreviewOptions` and page-stream callbacks.
