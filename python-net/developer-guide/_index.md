Welcome to the Developer Guide for GroupDocs.Annotation for Python via .NET. This section provides practical, runnable code examples that show how to use every annotation feature in your own projects. Each example is also available in the companion [GitHub repository](https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-Python-via-.NET).

## Prerequisites

Before you start, review:

- [System Requirements](https://docs.groupdocs.com/annotation/python-net/system-requirements/) — supported platforms, Python versions, and native dependencies.
- [Installation](https://docs.groupdocs.com/annotation/python-net/installation/) — install from PyPI or a pre-downloaded wheel.
- [How to Run Examples](https://docs.groupdocs.com/annotation/python-net/how-to-run-examples/) — set up a project and run any example locally or in Docker.

We recommend [obtaining a temporary license](https://purchase.groupdocs.com/temporary-license/) so you can test every feature without the evaluation-mode limits.

## In this guide

- [Basic Usage](https://docs.groupdocs.com/annotation/python-net/basic-usage/) — the core operations: add every annotation type, read and remove annotations, and attach comments and replies.
- [Advanced Usage](https://docs.groupdocs.com/annotation/python-net/advanced-usage/) — loading documents from a path, stream, or password-protected file, and saving with annotation-type and page-range filters.
