Each page here answers one whole question — the design, the code that runs, and the parts that are
easy to get wrong — and links to a repository you can clone and run.

* [Write AI review comments into documents]({{< ref "annotation/net/use-cases/write-ai-review-comments.md" >}}) — turn a model's `{quote, comment}` findings into highlights with reply threads, in PDF, Word, Excel and PowerPoint.
* [Build an annotation UI for your web app]({{< ref "annotation/net/use-cases/build-annotation-ui-for-web-app.md" >}}) — page images, a canvas and four endpoints, with no viewer component and no front-end framework.
